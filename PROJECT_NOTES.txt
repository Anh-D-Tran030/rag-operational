RAG OPERATIONAL — DEMO NOTES

Purpose
  Hybrid document retrieval and text-to-SQL for venue operational records,
  with PII redaction, schema-aware SQL generation, and a faithfulness gate.

Local setup
  1. Create a Python 3.12 virtual environment.
  2. Install the API: pip install -e .
  3. Copy .env.example to .env and provide OPENROUTER_API_KEY.
  4. Start Qdrant: docker compose -f infra/docker-compose.yml up -d qdrant
  5. Load demo data:
       python3 scripts/ingest_corpus.py --manifest corpus/v1.yaml
  6. Start the API:
       uvicorn src.api.main:app --host 0.0.0.0 --port 8000

Optional UI
  Install with: pip install -e '.[ui]'
  Run with:    streamlit run app/streamlit_app.py

Container
  docker build -t rag-operational .
  The image seeds operational.db from data/fixtures. Qdrant document ingestion
  remains a separate bootstrap step using scripts/ingest_corpus.py.
